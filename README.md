## ✍️ 손글씨·도장 누끼따기

종이에 쓴 서명이나 찍은 도장을 사진으로 찍으면, 배경을 지우고 **투명 PNG**로 만들어 줍니다.
계약서·견적서·한글(HWP) 문서에 서명이나 도장을 넣을 때 쓰기 좋습니다.

### 주요 기능

- **사진 불러오기** — 끌어다 놓기, 클릭해서 선택하기, 복사한 사진 붙여넣기(Ctrl+V / ⌘V)
- **진하기 기준 조절** — 흐린 글씨는 살리고 종이 질감과 그림자는 지웁니다
- **글씨 색 바꾸기** — 검정·파랑·빨강 중에서 고르거나, 도장이나 색 펜의 원래 색을 그대로 유지합니다
- **보정** — 90° 회전, 미세 회전, 출력 크기 조절, 저장 범위 지정(파란 상자를 끌어서 조절)
- **잡티 확인** — 버튼을 누르고 있는 동안 저장될 부분을 붉게 표시합니다
- **내보내기** — 투명 PNG 저장, 투명 복사, 흰 배경 복사
- **모바일 대응** — 카카오톡·네이버 같은 앱 안의 브라우저에서도 저장하는 방법을 안내합니다

### 개인정보

사진은 **서버로 보내지 않습니다.** 모든 처리가 사용자의 브라우저 안(Canvas)에서 끝납니다.

### 사용 팁

- 한글(HWP)에 붙여넣을 때는 `[편집] → [골라 붙이기]`에서 PNG 형식을 고르세요.
- 붙여넣은 이미지가 검게 보이면 `투명 PNG 저장`을 누른 뒤 `[입력] → [그림]`으로 넣으세요.

### 기술 스택

`HTML` `CSS` `JavaScript` `Canvas API` `Clipboard API` `GitHub Pages`

별도 라이브러리나 서버 없이 HTML 파일 하나로 동작합니다.
